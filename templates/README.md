# Go Templates
This README file summarises the purpose of the different Go Templates here.

## Footer (footer.gohtml)
Template that contains information about our organisation and acknowledgements to the IKU Womxn in STEM hackathon run by KCL's, Imperial's and UCL's Womxn in STEM societies in addition to their partners and sponsors.

## Header (header.gohtml)
Template that contains metadata for the website in addition to a link to the css stylesheet and title for the tabs of each webpage.

## Index (index.gohtml)
Homepage for the Hub

## My Calendar (my-calendar.gohtml)
Student's calendar is shown on this page.

## My Course (my-course.gohtml)
Details related to the student's course, weightings and modules are shown on this page.

## My Learning (my-learning.gohtml)
Details relating to their assignments, lectures and content are shown on this page.

## My Societies (my-societies.gohtml)
Details relating to different societies they have signed up to through the university are shown here.

## Navigation (nav.gohtml)
Template for the navigation bar to the different webpages on the website

## Login (login.gohtml)
Page for students to log into their accounts on The Hub

## Signup (signup.gohtml)
Page for students to register onto The Hub

# Styling Conventions

## Commit messages:
Based on the conventional commits styling convention and https://gist.github.com/qoomon/5dfcdf8eec66a051ecd85625518cfd13

- feat: implement a new feature
- fix: fixing a bug
- test: implement an unit test for a feature
- docs: adding documentation to the project
- style: improve code style
- perf: type of refactor that improves the perfomance of the application
- refactor: rewriting or restructuring code (doesn't change behaviour)
- build: "changes involving build tools, dependencies, project version"
- chore: anything else that does not fit into the categories above

## Branch naming conventions:

- 'feature/insert_feat_here' when you want to implement a new feature on a separate branch
- 'fix/insert_fix_here' when you want to create a debugging branch
